# Launch video

A 22-second square video (1080×1080, 30 fps) for sharing the first public
release on LinkedIn and other feeds.

| File | What it is |
|---|---|
| `launch.mp4` | The video, with its soundtrack |
| `launch.jpg` | Poster frame (also frame 0 of the MP4, so feeds show it as the thumbnail) |
| `launch-preview.gif` | Silent 480 px preview shown at the top of the main README |
| `plan.md` | Angle, storyboard and sound plan |
| `launch.html` | The composition: every frame is a pure function of time |
| `render.js` | Captures each frame with Playwright |
| `synth.py` | Generates the soundtrack (120 BPM, C major, effects on the same beat grid) |
| `build.sh` | Rebuilds everything above in one command |

Everything on screen is the repo's own fictional example data and the real eval
results (99% of checks passed with the skills, 60% without, 33 prompts). The
music and sound effects are generated by `synth.py`, so there is nothing to license.

## Rebuild after a change

Update the numbers or skill names in `launch.html` (and `plan.md`), then:

```bash
./media/launch/build.sh
```

Needs Node 22 with Playwright (Chromium), Python 3 with numpy, ffmpeg, and the
Inter and Noto Color Emoji fonts.
