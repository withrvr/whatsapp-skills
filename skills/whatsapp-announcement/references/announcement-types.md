# Announcement types

Each type: the skeleton (line by line), then what to watch. `[brackets]` are
slots to fill from the brief. Drop any line the brief has nothing for. Never
fill a slot with an invented value.

## 1. Meeting / class / session notice

```text
📅 *[What] on [Day, Date]*

[One line: purpose or agenda.]

⏰ [Time] ([time zone if mixed audience])
📍 [Place]  or  🔗 *Join:* [link]
📝 [What to bring / prepare]

[Action + deadline, e.g. "Reply here if you can't make it."]
[Name, role]
```
Watch: agenda in one line; for online meetings put ID and passcode in `` `inline code` `` on their own lines.

## 2. Change: rescheduled, moved, cancelled

```text
⚠️ *[What] [moved/cancelled]*

~[Old date/time/place]~ → *[New date/time/place]*
[Reason in one line, if the user gave one.]

[What people need to do now, if anything.]
```
Watch: say "cancelled" or "moved" in the headline, never bury it. If cancelled with no new date, say when they'll hear.

## 3. Reminder (day before, hour before)

```text
⏰ *Reminder: [what] [tomorrow/today] at [time]*

📍 [Place or link]
✅ [The one thing to remember to bring/do]
```
Watch: shorter than the original notice. Lead with the time.

## 4. Deadline / submission / fee due

```text
📌 *[What] due [Day, Date], [time]*

[What exactly to submit/pay and how.]
💳 [Amount + payment method, copied exactly]  or  📝 [Form/link]

[Who to contact for problems.]
```
Watch: amount, account/UPI and deadline verbatim. Late policy only if the user gave one.

## 5. Alert (urgent)

```text
🚨 *[Alert]: [what], [when]*

[Impact: who/what is affected, for how long.]
[What to do right now.]

[Source or authority, if it's not the sender.] [Next update time.]
```
Watch: no greeting, no emoji beyond 🚨/⚠️, no jokes. Only verified info, with its source. If the user is unsure, write "Unconfirmed:" and say what they're checking.
Examples: water/power cut, lift maintenance, gas leak drill, heavy rain/school closure, server outage, security incident, lost child, road closure.

## 6. Information share: policy, rule, process change

```text
📢 *[New/updated] [policy name], from [Date]*

[What changes, in 1-2 lines.]
- [Point 1]
- [Point 2]
- [Point 3]

[Link to the full document.]
[Who to ask.]
```
Watch: say what's different from before, not the whole policy.

## 7. Study material / resource share

```text
📚 *[Subject/Topic]: [what's shared]*

[What it is and what to do with it, by when.]

📄 [Item 1]: [link or "PDF attached"]
📄 [Item 2]: [link]
🎥 [Recording]: [link]

[Test/class it's for.]
```
Watch: label every link; suggest clean PDF names in Notes; mention if links need a college login.

## 8. Results / selections / lists

```text
🏆 *[Results/Selection] for [what]*

[One warm line.]

1. [Name]: [detail]
2. [Name]: [detail]

[Next step for selected people + deadline.]
[One line for those not selected, if appropriate.]
```
Watch: spell names exactly as given; don't publish marks or private info the user didn't clear for a group.

## 9. Holiday / closure / office timings

```text
🗓️ *[Office/School/Shop] closed on [Day, Date]* for [occasion]

[Reopens: Day, Date, time.]
[Emergency contact, if any.]
```
For a list of holidays: one line per holiday, `*Day, Date* · Occasion`.

## 10. Fundraiser / contribution / collection

```text
🙏 *Contribution for [cause]*

[Why, in 1-2 lines. Who it helps.]

💰 [Suggested amount or "any amount"]
💳 *UPI:* [exact UPI ID]  ([name it shows])
📅 *By:* [Day, Date]

[Who's collecting + how the account will be shared.]
```
Watch: the UPI ID and the display name exactly as given. Say how money will be accounted for if the user mentioned it.

## 11. Volunteers / sign-ups / headcount

```text
🙋 *Volunteers needed for [what], [Day, Date]*

[Roles or slots, one per line.]

[How to sign up: poll / form / reply with your name.] [Deadline.]
```
Watch: suggest a poll (up to 12 options) for slot choice.

## 12. Welcome message for a new group or new members

```text
👋 *Welcome to [group name]!*

This group is for [purpose].

*A few rules:*
1. [Rule]
2. [Rule]
3. [Rule]

[Where to find key info: pinned message, link.]
[Admin contact.]
```

## 13. Group rules / reminder of rules

Same as the rules block above. Lead with why ("to keep this group useful for all 200 of us"), keep it to 3-5 rules, end with what happens on repeat violations only if the user gave it.

## 14. Weekly digest / roundup (several items)

```text
🗞️ *[Group] update: week of [Date]*

*1. [Item title]*
[1-2 lines + link]

*2. [Item title]*
[1-2 lines + link]

*Coming up:* [next date]
```
Watch: number the items so people can reply "re 2".

## 15. New joiner / farewell / achievement in a team group

```text
🎉 *Please welcome [Name]!*

[Name] joins us as [role] in [team], [one line of background the user gave].
[What they'll work on / who they'll work with.]

Say hi! 👋
```
Farewell: thanks + what they did + where they're going (if shared) + farewell plan.

## 16. Job opening / hiring post

```text
💼 *Hiring: [Role], [Company], [City or Remote]*

[What the role does, 1-2 lines.]
- [Experience]
- [Key skill or requirement]
- [Salary or range, only if the user gave it]

📩 *Apply:* [link or email] by *[Day, Date]*
[Referrer line: "Happy to refer, message me" if it's the user's own company.]
```
Watch: say who's hiring (company or recruiter) and how to apply. No "DM for details" without a real contact. Never ask candidates for money; a "registration fee" is a scam sign.

## 17. Urgent help request (blood, medical, missing person)

```text
🆘 *Urgent: [what's needed], [Day, Date]*

[Blood group + units] needed for [patient first name or "a patient"] at [hospital, city].
📞 Contact: [name, number]
🕐 Needed by: [time]

Please share only if you can help or know someone who can.
```
Watch: **always put the date in the first line.** Old blood requests keep getting forwarded for months, long after they're needed. Include a verified contact; say "Update: arranged, thank you" when it's done. Missing person: last seen where and when, a description, the police station or a family contact, never a home address.

## 18. Meeting minutes from your own notes

```text
📝 *Minutes: [meeting], [Day, Date]*

*Decided*
1. [Decision]

*Action items*
- [Owner]: [task] by *[Day, Date]*

*Next:* [date]
```
Watch: from a chat discussion instead of notes, use `whatsapp-catchup`.

## 19. Daily stand-up / status update in a team group

```text
*[Name], [Day, Date]*
✅ Done: [item]
🔜 Today: [item]
⛔ Blocked: [item + who can unblock], or "none"
```
Watch: one line per item, no paragraphs; the whole thing fits one phone screen.

## 20. Buy, sell, rent, flatmate, carpool posts (community groups)

```text
[emoji] *[For sale / Looking for / For rent]: [item or need]*

- [Key detail: model, size, condition, dates, route]
- [Key detail]
💰 [Price or budget]
📍 [Area] · 📞 [Contact or "DM me"]
```
Watch: price and area always. Carpool: route, days, time, seats, cost share. Flatmate: area, rent share, move-in date, preferences only if the user stated them (no discriminatory filters).

## 21. Event recap and photo share

```text
🙏 *Thank you for making [event] special!*

[One or two specific highlights.]

📸 Photos: [album link]
[What's next, if anything.]
```
Watch: thank volunteers by name only if the user listed them; link one album, not twenty photos in the chat.

## Native features to suggest

- **Poll** for choices and headcount (not "reply 1 or 2").
- **Event** for meetings, classes and meetups in groups and communities: people get reminders and can RSVP.
- **Pin** for anything people must find again this week.
- **Community announcement group** to send one notice to several groups at once.
