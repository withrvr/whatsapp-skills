# Reply situations

Shapes for the replies people struggle with most. Line 1 always carries the answer.

## Yes, with conditions
Shape: yes → the condition or detail (time, price, scope) → next step.
"Yes, I can take it. I'll need the files by Wednesday to deliver Friday."

## No, politely
Shape: thanks/acknowledge → the no, clearly → short reason (only if the user gave one) → alternative (if any).
"Thanks for thinking of me! I can't take this one on this month, my plate's full till the 30th. Happy to help in December if it still works."
Avoid: "I'll try" when the user means no; invented excuses.

## Not now / need time
Shape: acknowledge → when they'll hear back (a day, not "soon") → what you need meanwhile (if anything).
"Got it, thanks. Let me check with my team and get back to you by Thursday."

## Need more information
Shape: short acknowledgement → numbered questions (if 2+) → why you need them (one line, optional).

## Counter-offer / negotiation
Shape: appreciation → your number or terms, concrete → what makes it work for them → open to a call.
Price talk on WhatsApp: state numbers exactly, with currency and what's included.

## Pushing back on a boss or client
Shape: agree with the goal → the constraint as a fact → two options with trade-offs → ask them to pick.
"Totally agree we need it before the launch. With the current scope, Friday isn't possible. We can (1) ship the core flow Friday and the reports next Wednesday, or (2) ship everything next Wednesday. Which works better?"

## Angry customer or upset person
Shape: acknowledge the specific issue → apologise for the impact (if the user's side is at fault) → the fix + when → direct contact.
No defensiveness, no policy quotes in line 1. If it's escalating, offer a call.

## Setting a boundary (late-night work messages, constant favours)
Shape: friendly → the boundary as a plan, not a complaint → when you'll respond.
"Saw this, I'll pick it up first thing tomorrow morning."

## Recruiter or HR
- Interested: thanks → interest + one line of fit → availability → ask about next step.
- Not interested: thanks → not looking right now → (optional) "happy to stay in touch".
- Salary question: give the number if the user gave one; else "I'd like to understand the role better first, happy to discuss on a call."

## Client asking for a discount
Shape: appreciate the relationship → what you can offer instead (scope, payment terms, a smaller discount if the user allows) → keep the door open.

## Family group / elders
- Answer respectfully in the language and script used in the group.
- "Good morning" forwards don't need replies; if the user wants one, a short "Good morning 🙏" or a namaste fits.
- Forwarded health or news claims: if the user wants to push back, be gentle and factual, link a reliable source the user provides, don't mock.

## Thanking people for wishes (birthday, wedding, promotion)
Group: one message thanking everyone. 1:1: short and personal, mention something from their message.

## Condolence messages received
"Thank you so much for your kind words, it means a lot." No need to reply individually to every one; the user can send one message to a group.

## Wrong number / unknown sender
Short and safe: "Hi, I think you have the wrong number." Don't share the user's name or details.

## Suspected scam
Don't engage. Tell the user why it looks like a scam and what to do. See SKILL.md §Suspicious messages.
