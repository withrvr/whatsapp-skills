# 1:1 message playbook

Each entry: the shape (line by line), the default dials, and the mistake to avoid.
Shapes are orders of ideas, not fixed wording. Merge lines when the message is short.

## Work: up the chain

### Running late / can't make it
Shape: what's happening + new ETA → what's covered → what they need to do (often nothing).
Dials: short · friendly-professional · plain · no emoji.
Avoid: a paragraph of excuses. One reason, one line.

### Sick leave / personal leave
Shape: not coming + dates → reason at the level the user shares → handover (who covers, where things are) → reachable or not.
Dials: short · friendly-professional · plain.
Avoid: over-sharing medical detail; promising availability the user didn't offer.

### Work-from-home or schedule request
Shape: the request with exact dates → why (one line) → how work continues → "Is that okay?"
Avoid: asking as if it's already decided, unless the user says it's just an FYI.

### Status update / task done
Shape: what's done (with the link) → what's pending + when → anything you need from them.
Dials: short or medium · light formatting if 3+ items (a short list).

### Escalation or problem report
Shape: the problem in one line → impact (who/what/when) → what you've tried → what you need, by when.
Avoid: blame. State facts.

### Asking for a raise, review, feedback, or a meeting
Shape: the ask → a 15-30 minute slot proposal → one line of why.
Avoid: making the case in WhatsApp. The message gets the meeting; the meeting makes the case.

## Work: across and outward

### Colleague favour or handover
Shape: context in one line → the specific ask → by when → thanks.
Easy out: "No worries if not, I'll ask Sam."

### Client or vendor follow-up
Shape: reference the last touchpoint (date, proposal, invoice no.) → the one thing you need → by when.
Dials: friendly-professional · plain. Second follow-up: shorter, same ask.

### Payment reminder (business)
Shape: invoice no. + amount + due date → how to pay (exact) → "Ignore if already paid, thank you."
Avoid: threatening tone in first and second reminders.

### Booking, rescheduling, cancelling (doctor, salon, tutor, service)
Shape: name + current booking → what you want (new slot options) → contact.
Short. Two concrete slot options get faster answers than "when are you free".

### Complaint to a business / landlord / society office
Shape: the issue with dates and specifics → impact → what you want done, by when → reference (order no., flat no.).
Tone: firm, not rude. Facts in order.

## HR, recruiters and jobs

### First message to a recruiter or hiring manager
Shape: who you are (role, years, one standout fact) + how you found them → the role you're interested in → ask for a short call or the right person → CV attached note.
Dials: short or medium · friendly-professional. Notes: "Attach CV as PDF: Firstname_Lastname_CV.pdf".

### Follow-up after an interview
Shape: thanks + role + date of interview → one specific thing you enjoyed or can add → asking about next steps/timeline.

### Accepting / declining an offer
Accept: thanks → acceptance + joining date → next steps (documents, formal email).
Decline: thanks → decision in line 1 or 2 → brief reason (optional) → door open.

### Salary or notice-period negotiation
Shape: appreciation → the specific number or date you want → one-line justification → "Happy to discuss on a call."
Avoid: ranges that start below what the user wants.

### Telling your manager you're resigning (heads-up)
Shape: ask for a quick call today/tomorrow, nothing more. The conversation happens live, the letter by email.

## New contacts

### Cold first message (referral)
Shape: who you are + who referred you → why them specifically → one small ask (a 15-min call, a quote, an answer) → thanks.
Avoid: "Hi" alone, a pitch wall, asking for a call without saying what it's about.

### Message after meeting someone at an event
Shape: where you met + a detail they'll remember → the follow-up you promised (link, intro, file) → light next step.

### Neighbour, PG owner, broker, seller (OLX, Marketplace)
Shape: who you are (flat no., the listing) → question or offer → when you can meet/pay.
Safety: never share OTPs; meet in public places for sales. If the brief involves "pay first to reserve" from a stranger, add a caution in Notes.

## Personal

### Congratulations (job, wedding, baby, exam, promotion)
Shape: congrats with the specific thing → one personal line → a light wish or "let's celebrate".
Dials: short · warm · emoji few (🎉 fits).

### Birthday wish
Shape: wish + name → one personal memory or in-joke if the user gave one → wish for the year.
Avoid: generic poem-style wishes unless asked.

### Thank you
Shape: what they did, specifically → what it meant/changed → (optional) return offer.

### Apology
Shape: own it in line 1 (specific) → impact acknowledged → what you'll do differently or the fix → no "but".
Dials: short · apologetic · no emoji · no jokes.

### Condolence
Shape: "I'm so sorry to hear about [name/relation]." → one warm memory or quality, if the user knows one → offer specific help or "No need to reply." 
Dials: short · respectful · no emoji (🙏 only if the user's culture expects it) · no exclamation marks.

### Checking in on someone unwell or going through something
Shape: thinking of you → a specific offer (drop food, call later) → no pressure to reply.

### Making or breaking plans
Make: idea + 2 options for time → place → "In?"
Break: sorry + reason (brief) → a concrete alternative date.

### Asking a friend to repay money
Shape: friendly opener → amount + what for → UPI ID → "whenever you can this week" or the real deadline.
Second nudge: one line.

## School and college (1:1)

### Parent to teacher (absence, query)
Shape: "Good morning Ma'am/Sir, this is [parent name], [child]'s parent from [class/section]." → the point → thanks.
Dials: short · respectful · plain.

### Student to teacher / professor
Shape: name + roll no./class → the question or request (extension, doubt, recommendation) → deadline context → thanks.
Avoid: late-night messages framed as urgent; mention in Notes if the brief implies it.
