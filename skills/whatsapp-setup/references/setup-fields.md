# Setup fields

Limits marked "about" are soft: the app may cut or collapse longer text. The
About line is a hard limit.

## Personal account

| Field | Limit | What it's for | Template |
|---|---|---|---|
| About | 139 characters (hard) | One line under your name | `[Role] at [place] · [one human detail]` or availability: `In meetings till 6, text me` |

## WhatsApp Business profile

| Field | Limit | What it's for | Template |
|---|---|---|---|
| Business name | short | How customers find you | `[Brand] [what] [area]` if the brand alone is unclear: "Sweet Crumbs Bakery Baner" |
| About | 139 characters | A tagline under the name | `[What you do] in [area]. [Hours or promise]` |
| Description | about 512 characters | What you sell, where, how to order | What + for whom → area/delivery → how to order → hours → website |
| Address, hours, email, website | fields | Shown on the profile | Copy exactly from the user |
| Greeting message | short | Auto-sent on first contact and after 14 days quiet | Who they reached → what to send → one expectation (lead time, hours) |
| Away message | short | Auto-sent outside hours (or always, or on a schedule) | Thanks → when you'll reply (real hours) → urgent alternative if any |
| Quick replies | up to 50, each with a `/shortcut` | Saved answers typed with `/` | One question per reply, complete on its own |
| Labels | up to 20 | Sort chats | 4-6 labels matching the order flow |
| Catalog item | name, price, description, link, code | Product pages inside WhatsApp | Name: item + key variant. Description: what's included, sizes/material, care, delivery time |
| Collections | names | Group catalog items | Customer words: "Birthday cakes", "Under ₹500" |

### Quick replies most businesses need

| Shortcut | Answers |
|---|---|
| `/price` | Price list or "prices start at…", with the catalog link |
| `/loc` | Address + Google Maps share link + landmark |
| `/hours` | Opening hours, holidays |
| `/pay` | Payment methods: UPI ID, card, cash on delivery (exact) |
| `/delivery` | Areas, charges, how long |
| `/order` | What to send to place an order |
| `/thanks` | After an order or payment |
| `/review` | Review link request |
| `/followup` | Gentle nudge for an open enquiry |

## Groups

| Field | Limit | What it's for | Template |
|---|---|---|---|
| Group name | short | Found in chat list and search | `[Place or org] [audience] [purpose]`: "Sunrise B Wing Residents" |
| Description | about 2,048 characters | Purpose, rules, admins; shown on join | Purpose (1 line) → rules (3-5, numbered) → what's not allowed → admins → where key info is (pinned) |
| Group settings advice | n/a | | Suggest in Notes: "Only admins can edit group info", "Approve new members" for open links |

## Communities

| Field | What it's for | Template |
|---|---|---|
| Community name | Umbrella over several groups | `[Org/Place] Community`: "Sunrise Towers Community" |
| Description | What the community is and which groups are in it | Purpose → groups and what each is for → announcement group is admin-only |
| Announcement group welcome | First thing members see | One line of purpose + how to join sub-groups |

## Channels

| Field | What it's for | Template |
|---|---|---|
| Channel name | Found by search | Topic + audience or place: "Pune Weekend Plans" |
| Description | Why follow | What you post + how often + who runs it: "5 things to do in Pune every Friday at 6 pm. By Anaya, local food and events writer." |

## Description template (business)

```text
[What you sell] for [who], made [how / where].

📍 [Area] · 🚚 [Delivery areas or "pickup only"]
🕙 [Hours]
📝 To order: [what to send]
🌐 [Website, if any]
```

## Group rules starter set

Pick 3-5 that fit, in the user's words:

1. Only [topic] related messages, please.
2. No forwards, promotions or "good morning" messages.
3. Be respectful, no personal attacks.
4. Urgent issues: message the admins directly.
5. Admins may remove messages or members that break these rules.
