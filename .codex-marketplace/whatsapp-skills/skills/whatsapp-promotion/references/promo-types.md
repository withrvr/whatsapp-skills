# Promotion types

Skeletons, line by line. `[brackets]` are slots from the brief; drop lines with no fact behind them.

## 1. Offer / sale

```text
[emoji] *[Benefit or offer headline]*

[What's included or what's on sale, 1-2 lines.]

~[old price]~ *[new price]*  or  *[X]% off* on [what]
📅 [Valid from/till]
👉 [One call to action + link]

– [Business]
Reply STOP to stop these messages.
```

## 2. Festive greeting + offer

```text
[Festival greeting, genuine, 1-2 lines.]

[Blank line, then the offer in 2-3 lines.]
👉 [Call to action]

– [Business]
```
Never: blessing and discount in the same sentence. Condolence or tragedy days: no promo.

## 3. Product launch / new service

```text
✨ *New: [product/service]*

[What problem it solves, in the customer's words.]
- [Feature → benefit]
- [Feature → benefit]

💰 [Launch price / intro offer + validity]
👉 [Call to action]
```

## 4. New arrivals / restock / back in stock

```text
🛍️ *[Item] is back in stock!*  /  *New arrivals: [collection]*

[Sizes/colours/variants available, one line.]
💰 [Price]
👉 [How to order, e.g. "Reply with the photo of what you like"]
```
Watch: say the stock count only if the user gave it.

## 5. Course / webinar / workshop / coaching batch

```text
🎓 *[Outcome the learner gets]: [course name]*

📅 [Start date] · [duration / schedule]
💻 [Online/offline + where]
💰 [Fee, early-bird + its deadline]
✅ [Who it's for, one line]

👉 *Register:* [link]
```
Watch: no "guaranteed job/marks/returns". Credentials only as the user gave them.

## 6. Appointment / service reminder (salon, clinic, car service, tutor)

```text
Hi [Name], your [service] is due [this week / on Date].

Reply with a time that suits you, or book here: [link]
– [Business]
```
Short and personal; send to the individual, not a group.

## 7. Enquiry follow-up (one follow-up, max two)

```text
Hi [Name], following up on your enquiry about [item/service] on [day].

[One new useful detail: availability, a photo, a slot.]
Shall I [book / keep it aside] for you?
```

## 8. Referral ask

```text
Hi [Name], thank you for [being a customer / your order]! 🙏

If you know someone who'd like [service], share this: [link or number].
[Referral benefit, only if real.]
```

## 9. Review request

```text
Hi [Name], thank you for choosing [Business]!

If you have a minute, a Google review would really help us: [review link]
```
Never offer a reward for positive reviews only. Never write the review for them.

## 10. Catalog / price list share

```text
📋 *[Business] price list ([month/season])*

[3-6 top items · price, one per line]
Full catalog: [catalog link]

👉 [How to order]
```

## 11. Win-back / we miss you

```text
Hi [Name], it's been a while! [Short, warm line.]
[A real incentive, if the user has one.] [Call to action.]
```

## 12. Property / vehicle / rental listing

```text
🏠 *[Type] for [rent/sale]: [area]*

- [Size / configuration]
- [Key feature]
- [Floor / facing / furnishing]
💰 [Price / rent + deposit]
📞 [Contact]
```
Facts exactly as given. No "best deal in the city".

## 13. Event tickets (paid)

```text
🎫 *[Event]: [Day, Date]*

[One line on what it is and who's performing/speaking.]
📍 [Venue] · ⏰ [Time]
💰 [Ticket tiers]
👉 *Tickets:* [link]
```

## 14. Creator / affiliate promo

```text
[Personal hook in creator voice, 1 line.]
[Why you use/recommend it, 1-2 lines, honest.]
[Code/discount if real.] [Link]
[Disclosure: "Paid partnership" / "affiliate link" when applicable.]
```

## Calls to action that work on WhatsApp

- "Reply *YES* and we'll confirm your order."
- "Tap to order: https://wa.me/91XXXXXXXXXX?text=…" (prefilled text, URL-encoded)
- "Reply with the photo of the item you like."
- "Book your slot: [link]"
- One per message.
