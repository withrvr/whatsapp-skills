# Status patterns

A status is read in about a second. Each pattern below is 1-3 short lines.

## Personal

| Situation | Pattern | Example |
|---|---|---|
| Milestone (job, graduation, results) | The news + one feeling | "New chapter: joined Zeta as a Product Designer today ✨" |
| Birthday (own) | Thanks in advance or a line about the year | "Another trip around the sun. Grateful for all of you 🎂" |
| Birthday (someone else) | Name + wish + a light personal touch | "Happy birthday Maa! The reason this house runs 💛" |
| Festival | Greeting + one sincere line | "Shubh Deepavali! May your home be full of light and laughter 🪔" |
| Travel / moment | Place + feeling, or a caption | "Manali mornings ❄️" |
| Quote / thought | The line, credited if it's someone else's | "“Done is better than perfect.” – Sheryl Sandberg" |
| Availability | When + how to reach | "Travelling till Sun, 15 Nov. Slow replies, call if urgent." |
| Memorial / tribute | Name + one line, no emoji or 🙏 only | "Remembering Dadaji today. Miss you every day." |
| Exam / interview ask | A light request | "Exam tomorrow. Send good luck, not memes 🙏" |

## Business

| Situation | Pattern |
|---|---|
| Offer | Offer + validity + reply hook: "20% off all cakes today only. Reply 🎂 to order" |
| New product | "New:" + item + price + reply hook |
| Back in stock | Item + "back in stock" + sizes/qty (only if given) |
| Open/closed | "Open this Sunday, 10 am to 6 pm" / "Closed on Mon, 9 Nov for Diwali" |
| Countdown | "3 days to go: Winter Sale starts Fri, 20 Nov" |
| Social proof | A real customer quote, with permission, credited by first name |
| Behind the scenes | One line about the photo/video |
| Booking slots | "2 slots left for Saturday. Reply to book" (only if true) |

## Slide sets (2-5 statuses)

Use when the user has several points about one thing. Each slide stands alone.

1. **Hook**: the headline ("Workshop this Saturday!")
2. **Detail**: what/when/where (one line each)
3. **Proof or detail**: who it's for, price
4. **Call to action**: "Reply *YES* to register"

Label each output block `Status 1 of 4`, `Status 2 of 4`, …

## Caption rules (photo/video status)

- First line carries the whole point; the rest may be cut by the screen.
- Don't describe what's obviously in the photo.
- ~200 characters max, one emoji at most in personal captions.

## Text status visuals

The user chooses colour and font in the app. Suggest in Notes only when it helps:
dark background for serious/memorial, bright for offers and celebrations.
